# ⚡ AuraHabit - Modern Habit Tracker & Productivity Hub

AuraHabit is a modern, high-performance web application for tracking habits, visualizing long-term progress, building streaks, and gamifying personal growth.

![License](https://img.shields.io/badge/License-MIT-10B981?style=for-the-badge)

---

## ✨ Features

- 🎯 **Daily Habit Tracking**: Check-in habits, increment target counters (e.g., water intake, meditation sessions), and view live completion progress rings.
- 🗓️ **Weekly Grid View**: Matrix view to monitor habit performance across every day of the week.
- 🟩 **90-Day Activity Heatmaps**: GitHub-style activity grid visualization for tracking habit consistency over time.
- 📊 **Analytics Dashboard**: Interactive Chart.js charts for weekly completion rates and habit category breakdowns.
- ⏳ **Focus & Pomodoro Timer**: Preset timers (25m, 15m, 45m, 60m) linked directly to habits to auto-log them on session completion.
- 🏆 **100-Level Gamification System**: Earn XP, level up across a progressive curve (with Level 50 scaled to be a tough, prestigious milestone), and cap out at Level 100 MAX (`Supreme Habit Legend`).
- 🎖️ **Unlockable Badges**: Earn achievements for streaks, total completions, multi-category habits, and level milestones.
- 🎵 **Web Audio Synth & Celebration FX**: Synthesized audio chimes and confetti bursts upon habit completion and level ups.
- 🌙 **Dark & Light Themes**: Modern glassmorphism UI with theme toggling and motivational quote generator.
- 💾 **LocalStorage Persistence**: Auto-saves state locally in your web browser.

## 🚀 Getting Started

Since AuraHabit is built with standard modern HTML5, CSS3, and JavaScript, no `npm install` or node server setup is required.

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Sutharsan555/daily-habit.git
   cd daily-habit
   ```

2. **Open in Browser**:
   - Double click `index.html` or open it directly in your web browser.
